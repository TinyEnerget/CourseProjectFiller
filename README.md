# CourseProjectFiller

Инструмент для автоматизации заполнения курсовых проектов по теме **«Район нагрузок электрической сети»**. Генерирует варианты заданий со случайными параметрами и заполняет шаблон Word данными из конфигурации или из Excel-таблицы студентов.

## Возможности

- **Генерация вариантов** — создание нескольких вариантов с разными значениями нагрузок, напряжений, ОЭС и других параметров в заданных диапазонах.
- **Заполнение шаблона** — подстановка данных в параграфы и таблицы документа Word (нагрузки, генерация, напряжения, дополнительные данные, условия, план с кружками подстанций).
- **Пакетное заполнение по списку студентов** — чтение Excel-файла (номер варианта N, группа, курс, ФИО) и создание отдельного документа для каждого студента.
- **Экспорт в PDF** — опциональная конвертация созданных .docx в .pdf (флаг `--pdf`).

## Требования

- Python 3.7+
- См. [requirements.txt](requirements.txt)

## Установка

## Структура проекта

| Файл | Описание |
|------|----------|
| `fill_template.py` | Заполнение шаблона .docx по данным из JSON или словаря |
| `generate_variants.py` | Генерация N вариантов со случайными значениями по конфигу |
| `fill_from_excel.py` | Заполнение документов по списку студентов из Excel |
| `config_variants.json` | Конфигурация: ОЭС, диапазоны параметров, план (сетка, кружки, масштаб) |

| `Шаблон Район нагрузок электрической сети.docx` | Шаблон курсового проекта |

## Использование

### 1. Генерация нескольких вариантов заданий

Создаёт N файлов `variant_001.docx`, `variant_002.docx`, … в указанной папке:

```bash
python generate_variants.py --count 10
python generate_variants.py --count 5 --oes "Сибирь"
python generate_variants.py --count 20 --out-dir variants --config config_variants.json
python generate_variants.py --count 3 --seed 42
python generate_variants.py --count 5 --pdf
```

Параметры:
- `--count`, `-n` — количество вариантов (по умолчанию 1)
- `--oes` — зафиксировать ОЭС для всех вариантов (например, «Сибирь», «Центр»); иначе выбирается случайно
- `--out-dir`, `-d` — папка для сохранения .docx
- `--config`, `-c` — путь к `config_variants.json`
- `--template`, `-t` — путь к шаблону .docx
- `--seed` — seed для ГПСЧ (для воспроизводимости)
- `--pdf`, `-p` — дополнительно сохранять каждый вариант в PDF

### 2. Заполнение одного документа по JSON

Удобно для проверки шаблона или ручной подстановки данных:

```bash
python fill_template.py --template "Шаблон Район нагрузок электрической сети.docx" --data data_template.json --out result.docx
python fill_template.py --data data_template.json --out result.docx --pdf
```

Если `data_template.json` отсутствует, скрипт создаёт пример файла с описанием полей. Флаг `--pdf` создаёт также файл result.pdf.

### 3. Пакетное заполнение по списку студентов (Excel)

Для каждой строки в Excel создаётся свой .docx: данные варианта берутся из одного сгенерированного варианта, а номер проекта (N), группа, курс и ФИО — из соответствующих столбцов.

**Требуемые столбцы в первой строке:** `N`, `group`, `course`, `name`.

```bash
python fill_from_excel.py --excel students.xlsx --template "Шаблон Район нагрузок электрической сети.docx" --out-dir variants
python fill_from_excel.py --excel students.xlsx --config config_variants.json
python fill_from_excel.py --excel students.xlsx --out-dir variants --seed 100
python fill_from_excel.py --excel students.xlsx --out-dir variants --pdf
```

Параметры:
- `--excel`, `-e` — путь к Excel-файлу (по умолчанию `students.xlsx`)
- `--template`, `-t` — путь к шаблону .docx
- `--out-dir`, `-d` — папка для сохранения документов
- `--config`, `-c` — путь к `config_variants.json` (для генерации варианта)
- `--sheet`, `-s` — имя листа в Excel (по умолчанию — первый)
- `--seed` — seed для генерации варианта (один и тот же вариант для всех студентов)
- `--pdf`, `-p` — дополнительно сохранять каждый документ в PDF

Имена выходных файлов формируются по ФИО (столбец `name`) или по номеру строки.

### Конвертация в PDF (флаг `--pdf`)

Для создания PDF из .docx нужен один из вариантов:
- **Windows:** установленный Microsoft Word и пакет `docx2pdf` (уже в requirements.txt).
- **Альтернатива (любая ОС):** установленный LibreOffice; скрипт вызовет `soffice --headless --convert-to pdf`.

Без Word/LibreOffice флаг `--pdf` не создаст файлы; в консоль выведется подсказка.

## Конфигурация (config_variants.json)

- **oes_list** — список ОЭС с полем `name` и зимней температурой `theta_ohl` (°C).
- **table0_plan** — параметры плана: `rows`, `cols`, `min_circle_distance`, `grid_step_cm`, `max_distance_km`, `scale_cell`, `ps_a_side` (left/right/random).
- **draw_substation_circles** — рисовать ли кружки подстанций на плане (PNG).
- **circle_size_inches** — размер кружка в дюймах.
- **ranges** — диапазоны для случайной генерации: нагрузки (в т.ч. по 110 кВ и 10 кВ), генерация, напряжения ПС А, дополнительные данные; при необходимости задаётся `min_total_load` (МВт).

Подробные комментарии к полям есть в самом файле `config_variants.json`.

## Формат Excel (students.xlsx)

Первая строка — заголовки. Обязательные столбцы (регистр по возможности учитывается):

- **N** — номер варианта / курсового проекта (подставляется в параграф «на курсовой проект № …»).
- **group** — группа (параграф 4).
- **course** — курс (параграф 4).
- **name** — ФИО студента (параграф 5 и имя выходного файла).
